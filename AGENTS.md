## What Lovable manages

Rules outside this block are the project's own. Change the pieces below in
Lovable, not by hand. With the [Lovable MCP](https://mcp.lovable.dev)
connected, `send_message` asks Lovable to do it; otherwise ask the user to
use the editor.

- **Database.** Do not add or edit `supabase/migrations/` or `drizzle/`.
  Ask Lovable to change the schema.
- **Generated files.** Do not edit a file whose header says it is automatically
  generated.
- **AI gateway.** Keep model calls on Lovable's gateway, and keep
  `LOVABLE_API_KEY` out of browser code.
- **Connectors.** Lovable provides native connectors. `list_connectors` shows
  which are enabled; `add_connector` only returns the dashboard link. When a
  connector is enabled, calls go through the connector gateway and need
  `LOVABLE_API_KEY`. When Lovable does not provide one, users can bring their
  own key and store it in Secrets.
- **Secrets.** Lovable manages them. Do not put secret values in the repo.

## Alaq architecture
- Religious text is never hand-written: Quran from AlQuran.cloud, recitations from EveryAyah.com, hadith from fawazahmed0/hadith-api, duas from the Hisnul Muslim snapshot in `src/data/duas.json` — keeps every text traceable to a cited source (shown on /sources).
- Fetch remote text through `cachedJson` in `src/lib/offline-cache.ts`, and play audio through `playableUrl` — this is what makes saved content work offline, independent of the service worker.
- The service worker is generated by vite-plugin-pwa and registered only from `src/lib/pwa-register.ts` (guarded off in dev/preview/iframes) — prevents stale previews.
- User state (settings, bookmarks, last read, playback, dhikr) lives in localStorage via `useStored`; Lovable Cloud accounts hold only the profile display name — keeps the app usable signed-out and the hook hydration-safe.
- One global audio player (`AudioPlayerProvider` in __root) so recitation continues across pages.
- Offline Tajweed lessons speak through the device's Web Speech voice (`src/lib/device-voice.ts` + `useDeviceSpeech`), scripted only from bundled `tajweed-notes.ts` — no network or sign-in, so they work offline.
- The teacher bubble's resting spot is stored as edge + height fraction (`src/lib/bubble-position.ts`) so it survives rotation and resizes.
